The thesis

Generating beautiful HTML is easy.
Revising it together is the hard part.

AI can produce a polished document in seconds. Iterating on it as a team — picking the exact paragraph to rewrite, flagging what should change, agreeing on a tweak — is where everything slows down.

"We have great tools for making HTML. We don't have a great tool for revising it as a group." — the gap this tool tries to fill
The problem · three pains

You get a beautiful first draft.
Now what?

Three things break down the moment more than one person needs to touch the file.

01

Editing HTML isn't beginner-friendly.

For anyone not comfortable in code, raw HTML is intimidating. One stray bracket and the layout breaks. Most people screenshot and write "change this" instead.

02

Chat is slow and vague.

Every tweak is a round-trip to the AI. Broad feedback like "tighten this paragraph" or "this section feels dense" has nowhere to anchor.

03

No shared workspace for teams.

No editor where reviewers can mark things up together, see each other's notes, and converge on what the AI should change next.

The product

A small browser tool
between your AI and your team.

Drop in any HTML. Share the room link with anyone — no signup needed. Edit text inline, leave comments anchored to one element or the whole document, watch your teammates' changes appear in real time.

When you're done, export two ways: a clean HTML file you can ship, or a Markdown prompt bundling every edit and comment that you can feed back to Claude / GPT for the next revision.

Built for
Teams
on a deadline.

Three people, one document, ten minutes — instead of a Slack thread that never converges.

What it does

The whole loop in one browser tab.

01 · Edit

Inline text editing

Click any text and rewrite. Markers like "1." or "•" are editable as plain characters too.

02 · Structure

Add or remove blocks

＋ / ✕ toolbar duplicates or deletes paragraphs, cards, table rows and columns.

03 · Comment

Anchor or general notes

One element, multi-select, or whole-document. The AI gets the context.

04 · Collab

Real-time sync

Yjs CRDT — conflict-free. Two people in the same paragraph won't clobber each other.

05 · Undo

Real undo and redo

⌘Z / ⌘⇧Z. Works for text and structural changes. Won't undo your collaborator's edits.

06 · Export

Both ways

Clean HTML download, or Markdown prompt for any AI. Closes the loop.

How to use it

Four steps. Five minutes.

01

Upload

Drop your .html file onto the landing page. Anything generated by an AI or written by hand works.

02

Share

Click Share, copy the link, send it. Anyone with the link can join — no signup needed.

03

Edit and comment

Toggle between Edit and Comment modes. Rewrite text in place, leave anchored or general notes, hash things out with your team in real time.

04

Export — the loop closes here

Pick Download HTML for a clean file, or Hand off to AI to copy a Markdown prompt bundling your edits and every comment. Drop it back into Claude / GPT for the next revision.
