# HTML Editor 全功能学习指南（边看边做）

这是一份按“上手任务”组织的用户指南。
你可以从头做一遍，也可以按目录跳到你关心的功能。

## 0. 你会学到什么

完成本指南后，你将能独立完成：

- 上传并替换 HTML 文档
- 在四种模式间切换：阅读、编辑、拖拽、批注
- 修改文本、删除结构、复制模块
- 插入图片/视频、表格，并调整样式
- 用飞书/Notion 风格控件给表格加行列、拖动行列
- 添加元素批注与通用批注
- 多人实时协作、分享链接
- 导出干净 HTML 或导出给 AI 的 Markdown 提示词

---

## 1. 3 分钟快速上手（建议先做）

### 任务 1：打开房间

1. 启动项目后访问 room 页面。
2. 你会看到顶部工具条、模式切换按钮和中间画布。

你会看到：

- 左上角是“上传”
- 顶部中间是模式切换：阅读 / 编辑 / 拖拽 / 批注
- 右上角有“分享”“导出”

### 任务 2：改一段文字

1. 切到“编辑”模式。
2. 点击任意一段正文直接输入。
3. 观察右下角状态从“保存中…”变为“已保存”。

你会看到：

- 改动实时生效
- 文档结构不会被破坏

### 任务 3：留一条批注

1. 切到“批注”模式。
2. 点击一个元素（例如一段话或一个卡片）。
3. 在右侧输入批注，按“保存”或使用 ⌘ / Ctrl + Enter。

你会看到：

- 该批注绑定到具体元素
- 后续导出给 AI 时会带上锚点上下文

## 2. 模式说明（最重要）

## 2.1 阅读模式

适合预览，不会触发编辑操作。

推荐场景：

- 交付前检查版面
- 协作者只读浏览

## 2.2 编辑模式

用于内容与样式编辑，不用于拖拽重排。

你可以做：

- 直接改文本
- 选中元素后使用浮动工具条：添加、复制、样式、删除
- 选中表格单元格后打开表格控制条（加行/加列、菜单操作）

## 2.3 拖拽模式

用于结构重排，不用于文本编辑。

你可以做：

- 拖动普通区块改变前后顺序
- 拖动表格整体
- 拖动表格行/列重排

注意：

- 有辅助线表示“可放置位置”
- 松手后才会提交结构变更

## 2.4 批注模式

用于评审和反馈，不改原文。

你可以做：

- 给单个元素加批注
- 多元素选择后写同一条批注
- 添加“通用批注”（不绑定元素）

---

## 3. 文本与结构编辑

### 任务 4：复制和删除一个模块

1. 编辑模式下点击任意模块（段落、卡片、列表项等）。
2. 点击浮动工具条中的“复制”。
3. 再点击“删除”。

你会看到：

- 复制出来的新模块保留原样式
- 删除后结构会同步更新

### 任务 5：通过 + 菜单插入内容

1. 在编辑模式下选中一个模块。
2. 点击浮动工具条左侧 +。
3. 选择“图片 / 视频”或“表格”。

当前 + 菜单提供：

- 图片 / 视频
- 表格

说明：

- 菜单里已移除“链接”入口
- 链接能力仍可通过“整块跳转链接”按钮进行设置

---

## 4. 表格完整工作流（重点）

## 4.1 编辑模式：增删行列

### 任务 6：给表格新增一列、一行

1. 切到编辑模式。
2. 点击表格任意单元格，让表格控制条出现。
3. 使用上方/侧边的 + 控件新增列或行。

你会看到：

- 表格会整体重建并保留现有文本
- 新行列为空白可继续编辑

### 任务 7：列/行菜单操作

1. 点击列段或行段（不是拖拽，轻点即可）。
2. 在弹出菜单中选择插入、复制或删除。

适合场景：

- 快速调整表头结构
- 复制一整列配置

## 4.2 拖拽模式：重排表格

### 任务 8：拖动整张表格

1. 切到拖拽模式。
2. 鼠标移动到表格区域，出现表格 grip（抓手）。
3. 按住 grip 拖到目标位置后松开。

### 任务 9：拖动列、拖动行

1. 继续在拖拽模式。
2. 抓住列段（顶部短条）拖到目标列间隙。
3. 抓住行段（左侧短条）拖到目标行间隙。

你会看到：

- 辅助线出现
- 松手后列/行顺序真实变化

如果你看到辅助线但顺序不变：

- 确认当前房间已切到“拖拽”模式
- 确认松手时指针仍靠近目标位置
- 想取消本次拖拽时按 Esc

## 5. 图片 / 视频能力

### 任务 10：插入一个图片框

1. 编辑模式下用 + 菜单选择“图片 / 视频”。
2. 在占位框中上传、拖入或粘贴资源地址。

### 任务 11：调整尺寸与裁切

1. 点击图片/视频元素使其被选中。
2. 使用边角/边中手柄调整尺寸。
3. 对图片使用裁切功能，拖动可视区域。

你会看到：

- 尺寸调整有对齐与吸附体验
- 裁切后仍可继续移动和缩放

---

## 6. 样式编辑（Style Panel）

### 任务 12：改文字色、填充色、描边色

1. 编辑模式下选中一个元素。
2. 点击“样式”按钮打开样式面板。
3. 在 Text / Fill / Border 三种模式中切换并修改颜色。

### 任务 13：改字号、对齐、父级选择

1. 在样式面板使用字号滑杆或数字输入。
2. 用对齐按钮切换左中右。
3. 点击“选择父级元素”向上编辑容器样式。

补充：

- 面板会提取页面色板并记录最近使用色
- 支持 Hex 输入
- SVG 文本内容可直接改

---

## 7. 链接能力

当前有两类链接相关能力：

- 文本链接：针对可编辑文本内容
- 整块跳转链接：让整个模块在阅读模式可点击跳转

建议：

- 对按钮卡片、海报区块使用“整块跳转链接”
- 对正文中的关键词使用文本链接

---

## 8. 批注与评审协作

### 任务 14：元素批注 + 通用批注

1. 切到批注模式。
2. 点击元素后写一条元素批注并保存。
3. 再点“+ 通用”写一条全局建议。

你会看到：

- 元素批注可定位到具体块
- 通用批注适合写整体方向建议

### 任务 15：多人一起改

1. 点击“分享”复制房间链接。
2. 发给同事在同一个 room 打开。
3. 双方同时编辑，观察实时同步状态。

你会看到：

- 在线人数变化
- 保存状态实时更新

## 10. 常见问题排查

### Q1：拖拽模式下为什么不能改文字？

因为拖拽模式专门用于重排，编辑文字请切回“编辑”模式。

### Q2：为什么表格控制条没出现？

- 编辑模式：先点击单元格
- 拖拽模式：先把鼠标移到表格上

### Q3：看到辅助线但没变化？

- 确认鼠标松开时仍在合法放置区
- 再试一次拖拽（尤其是行列重排）

### Q4：为什么显示“仅本地”？

代表实时协作连接暂未建立，本地仍可继续编辑。恢复网络并重新打开房间后，再确认状态是否变为“单人”或“协作中”。
